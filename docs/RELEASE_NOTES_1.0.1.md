## 로컬 AI 교무수첩 1.0.1

선생님 본인 업무·학교 일정·학생 관찰을 더 정확하게 나누고, 전학 기록 처리와 두 번째 백업 위치를 더했습니다.
쓰던 기록·학생 명렬표·설정은 그대로 이어집니다.

### 고친 점
- 시험감독, 보강, 출장처럼 선생님 본인의 업무를 학생 관찰 기록으로 잘못 정리하던 문제를 고쳤습니다. 이제 교무 업무와 일정으로 정리됩니다.
- 학생자치회, 교직원 점심시간 같은 학교 일정이 학생부 자료로 들어가던 문제를 고쳤습니다. 일정표에만 표시됩니다.
- 일정 제목이 "교직원 점심은"처럼 어색하게 잘리던 문제를 고쳤습니다.
- 문장 가운데 있는 시각 앞에서 줄이 바뀌던 문제를 고쳤습니다.

### 새 기능
- 전학 기록을 적으면 학생 명렬표 비고에 전학 예정이 적히고, 전출·전입 서류 처리 할 일이 자동으로 만들어집니다.
- 설정 → 데이터에서 두 번째 백업 위치(D 드라이브 같은 다른 드라이브나 폴더)를 정하면, 백업할 때마다 그곳에도 사본을 저장합니다. C 드라이브가 초기화돼도 그 백업으로 되돌릴 수 있습니다. (학교 PC처럼 드라이브가 나뉘어 있으면 꼭 정해 두세요.)

| 이렇게 적으면 | 이렇게 정리됩니다 |
|---|---|
| 내일 3교시 영어 시험감독 | 교무 업무 + 일정 (학생부 자료에는 넣지 않음) |
| 3교시 영어 시험감독 중 2-1 학생들 대부분 끝까지 집중함 | 교무 업무 + 학생 관찰(학생 미지정) |
| 10.14. 15:15 학생자치회 실시 (안건 논의) | 일정만, 제목 "학생자치회 (안건 논의)" |
| 오늘 교직원 점심은 12:20 | 일정만, 제목 "교직원 점심 12:20", 한 줄로 표시 |
| 2학년 홍길동 OO중 전학예정 | 명렬표 비고 "OO중 전학 예정 (10월 12일 기록)" + 할 일 "홍길동 전출 서류 처리" |
| 3학년에 OO중에서 전입생 옴, 이름 홍길동 | 학생 추가('확인 필요') + 비고 "OO중에서 전입" + 할 일 "홍길동 전입 서류 처리" |

이미 잘못 정리된 기록은 기록 카드의 [AI로 다시 분류]를 누르면 새 규칙으로 다시 정리됩니다.
예전 버전이 기록에서 '전학생' 같은 이름으로 학생 칸을 만들었다면, 학생 명렬표에서 그 칸을 지워 주세요.

### 1.0.0에서 바꾸는 방법
1. 교무수첩을 시계 옆 아이콘의 [종료하기]로 끕니다.
2. 새 파일을 예전 파일과 같은 곳(예: 바탕화면)에 두고 켭니다.
3. 예전 파일을 휴지통으로 옮길지 물으면 [예]를 누릅니다. 기록·명렬표·설정·AI 모델은 그대로입니다.
