## 로컬 AI 교무수첩 1.0

생각나는 대로 한 줄 적으면, 이 PC 안의 AI가 학생, 할 일, 일정, 교무 업무로 나눠 정리해 줍니다.
학생 정보는 PC 밖으로 나가지 않습니다. 인터넷은 AI 모델을 받을 때와 나이스(학교 코드만 보냄)에만 씁니다.

### 받기

| 파일 | 설명 |
|---|---|
| **교무수첩_1.0.0.exe** (89MB, 권장) | 파일 하나 버전. 바탕화면 등에 두고 실행하면 됩니다. 설치·관리자 권한이 필요 없습니다. |
| **교무수첩_1.0.0.zip** (33MB) | 압축을 풀면 나오는 `teachers_note` 폴더의 `teachers_note.exe` 를 실행하는 버전. 파일 하나 버전이 백신에 막힐 때 쓰세요. |

- Windows 10/11 x64 전용입니다.
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요. 코드 서명이 없는 프로그램이라 뜹니다.
- 파일 하나 버전은 처음 켤 때 프로그램을 풀어 두느라 3초쯤 걸리고, 다음부터는 바로 켜집니다.

### 처음 쓸 때
1. 화면 맨 아래 입력창에 적고 [기록] 또는 Ctrl+Enter. 예) `오늘 3교시 2-1 홍길동 지각. 금요일까지 보호자 연락`
2. 설정 > AI 모델에서 'PC 권장' 표시가 있는 모델의 [받기]를 누릅니다(처음 한 번). 모델이 없어도 기록은 저장되고 직접 분류할 수 있습니다.
3. 설정 > 학교에서 학교를 찾아 정하고 나이스 인증키(무료)를 넣으면 시간표·학사일정을 자동으로 받아옵니다. 급식은 인증키 없이도 받습니다.
4. 학생 명렬표 화면에서 나이스 명렬표 엑셀을 가져오거나 화면에 끌어다 놓으세요.

### 주요 기능
- **오늘:** 오늘 업무 요약, 시간표, 급식, 오늘의 기록, 날이 바뀌어도 남는 메모. 칸 배치는 화면 크기에 맞춰 자동 또는 직접
- **기록:** 한 줄로 적으면 AI가 자동 분류하고, [기록] 버튼 옆 원형 게이지로 정리 진행을 보여 줍니다. 새로 정리된 항목 수는 메뉴 옆 초록 숫자로
- **일정표:** 주간·월간 일정과 학사력. 휴일, 휴업일, 업무, 방학을 색으로 구분
- **시간표:** 나이스에서 학교·학급·개인 시간표 자동 받기, 칸·교과·교사·학급·교실별 색, 방과후 요일. 일과 시간 설정은 탭 줄 오른쪽 톱니 단추
- **학생 명렬표:** 나이스 명렬표 가져오기, 이름·학급 찾기, 보일 항목 고르기, 엑셀 저장과 인쇄
  - 기록에 적은 전화번호·보호자 연락처·주소·생일 같은 개인정보는 학생부 자료가 아니라 명렬표의 그 학생 칸으로 들어갑니다. 이미 값이 있으면 덮어쓰지 않고 기록 카드에서 확인합니다.
  - 보호자 연락처는 관계와 번호로 4개까지, 연락처·주소 가리기(기록 화면에도 적용), 학생 상세에 변경 이력
- **학생부 자료:** 출결, 창체, 교과, 행특, 동아리, 진로, 자유학기, 일상생활로 참고자료를 모으고 AI 초안을 바탕으로 최종안 작성. 출결은 결석·지각·조퇴·결과를 사유별로 집계. 글자 수·바이트 한도 확인, 학급 최종안 엑셀 저장
- **교무 업무와 할 일:** 기록에서 해야 할 일을 뽑아 마감일과 알림 관리, 담당업무별 업무 기록
- **검색 / 보관:** 전체 검색, 백업과 되돌리기, 엑셀·CSV 내보내기, 학년도 마감 기록물(PDF)
- **창:** 윈도우 시작 시 자동 실행, 항상 위에 표시, 투명도(0~70%)

### 데이터 위치
- 기록·학생·AI 모델·백업은 `%LOCALAPPDATA%\teachers_note` 에 저장됩니다. 프로그램 파일을 바꾸거나 새 버전을 받아도 그대로 남습니다.
- 이전에 배포한 1.0을 쓰고 있었다면 데이터가 `%LOCALAPPDATA%\TeacherNotebookV2` 에 있습니다. 이 버전을 켜면 그 폴더 이름을 `teachers_note` 로 바꿔 그대로 옮깁니다(기록·모델·백업 모두). 예전 버전이 켜져 있으면 닫고 다시 켜면 옮겨집니다.
- 이전 1.0에서 AI가 학생부 자료로 넣었던 전화번호·주소 같은 개인정보는 처음 켤 때 한 번 학생 명렬표로 옮깁니다. 직접 쓴 관찰은 건드리지 않습니다.

### 알아 두실 점
- AI가 만든 학생부 초안은 참고 자료입니다. 나이스에 옮기기 전에 사실과 기재요령을 꼭 확인해 주세요. 나이스에 자동으로 입력하지 않습니다.
- AI는 그래픽카드 없이 CPU로 돕니다. 메모리 8GB PC에서는 2B 이하 모델을 권합니다.
- 알림은 프로그램이 켜져 있을 때 뜹니다. '윈도우 시작 시 자동 실행'을 켜 두면 놓치지 않습니다.
