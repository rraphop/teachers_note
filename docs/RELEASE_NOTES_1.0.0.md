## 로컬 AI 교무수첩 1.0

생각나는 대로 한 줄 적으면, 이 PC 안의 AI가 할 일·일정·학생 기록·교무 업무로 나눠 정리해 줍니다.
학생 정보는 PC 밖으로 나가지 않습니다. 인터넷은 AI 모델을 받을 때와 나이스(학교 코드만 보냄)에만 씁니다.

### 받기

| 파일 (표시 이름) | 크기 | 설명 |
|---|---|---|
| **Teachers_Note_1.0.0.exe** (교무수첩 1.0.0, 권장) | 135MB | 파일 하나 버전. 바탕화면 등에 두고 실행하면 됩니다. 설치·관리자 권한이 필요 없습니다. 이름을 `교무수첩_1.0.0.exe` 로 바꿔 써도 똑같이 동작합니다. |
| **Teachers_Note_1.0.0_portable.zip** (교무수첩 1.0.0 압축 버전) | 49MB | 압축을 풀면 나오는 `teachers_note` 폴더의 `teachers_note.exe` 를 실행합니다. 백신이 파일 하나 버전을 막을 때 쓰세요. |

- Windows 10/11 x64 전용입니다. 깃허브가 한글 파일 이름을 바꿔 저장하기 때문에 파일 이름은 영문입니다.
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요. 코드 서명이 없는 프로그램이라 뜹니다.
- 파일 하나 버전은 처음 켤 때 프로그램을 풀어 두느라 3초쯤 걸리고, 다음부터는 바로 켜집니다.

### 처음 5분
1. **AI 모델 받기**: 설정 > AI 모델에서 'PC 권장' 표시가 있는 모델의 [받기] (처음 한 번). 모델이 없어도 기록은 저장되고 직접 분류할 수 있습니다.
2. **학교 정하기**: 설정 > 학교(나이스)에서 학교와 담임반을 고릅니다. 급식은 바로, 시간표·학사일정은 나이스 인증키(무료)를 넣으면 받아옵니다.
3. **명렬표 넣기**: 학생 명렬표 화면에 나이스 명렬표 엑셀을 끌어다 놓습니다.
4. **적기**: 화면 맨 아래 입력창에 적고 [기록] 또는 Ctrl+Enter.

| 이렇게 적으면 | 이렇게 정리됩니다 |
|---|---|
| 금요일까지 상담 신청서 걷기 | 할 일 (마감 금요일) |
| 오늘 1교시 2-1 홍길동 지각 | 학생부 자료 · 출결 |
| 3-1 홍길동 번호는 21번 | 학생 명렬표 · 번호 |
| 홍길동 어머니 연락처 010-0000-0000 | 학생 명렬표 · 보호자 연락처 |
| 다음 주 수요일 15시 학년 협의회 | 일정 |
| 월 3교시 2-1 국어 과학실 | 개인 시간표 |
| OO군청에 행사 일정 물어봄 | 기타 기록 (이미 한 일은 할 일로 만들지 않음) |

### 주요 기능

| 화면 | 할 수 있는 일 |
|---|---|
| 오늘 | 오늘 업무 요약, 할 일, 시간표, 급식, 오늘의 기록, 날이 바뀌어도 남는 메모. 칸 배치는 화면 크기에 맞춰 자동 또는 직접 |
| 기록 | 한 줄로 적으면 AI가 자동 분류. 모든 기록 · 기타 기록 · 정리된 기록 세 탭. 기록 안에서 찾기(띄어 쓴 낱말이 모두 든 기록, 또는 구 그대로, 찾은 말 표시). 날짜·시각마다 줄을 나눠 보기 |
| 일정표 | 주간·월간 일정과 학사력. 휴일·휴업일·방학을 색으로 구분 |
| 시간표 | 나이스에서 학교·학급·개인 시간표 자동 받기, 교과·교사·학급·교실별 색, 방과후 요일, 입력창으로 보강·교체 넣기 |
| 학생 명렬표 | 나이스 명렬표 가져오기, 찾기, 보일 항목 고르기, 학생 추가 줄(학급과 다음 번호), 엑셀 저장·인쇄, 연락처·주소 가리기. 기록에 적은 번호·전화번호·보호자 연락처·주소·생일은 학생부 자료가 아니라 명렬표로(이미 값이 있으면 확인 후 반영, 변경 이력) |
| 학생부 자료 | 출결·창체·교과·행특·동아리·진로·자유학기·일상생활로 참고자료를 모으고 AI 초안을 바탕으로 최종안 작성. 출결은 사유별 집계, 글자 수·바이트 한도 확인, 학급 최종안 엑셀 저장 |
| 교무 업무·할 일 | 담당업무별 업무 기록. 앞으로 할 일만 뽑아 마감일과 알림 관리. 체크하면 완료 기록이 남음 |
| 보관 | 전체 검색, 하루 한 번 자동 백업과 되돌리기, 엑셀·CSV 내보내기, 학년도 마감 기록물(PDF/A) |
| 창 | 창을 닫아도 트레이에서 계속 실행(열기·기록하기·닫기·종료하기), 윈도우 시작 시 자동 실행, 항상 위, 투명도 |
| AI | 외장 그래픽카드가 있으면 GPU로 빠르게(시험한 PC에서 약 10배), 없으면 CPU로. 설정에서 'CPU 만'으로 바꿀 수 있음 |

### 데이터 위치
- 기록·학생·AI 모델·백업은 `%LOCALAPPDATA%\teachers_note` 에 저장됩니다. 프로그램 파일을 바꾸거나 새 버전을 받아도 그대로 남습니다.
- 먼저 배포된 1.0을 쓰고 있었다면 데이터가 `%LOCALAPPDATA%\TeacherNotebookV2` 에 있습니다. 이 버전을 켜면 그 폴더 이름을 `teachers_note` 로 바꿔 그대로 옮깁니다(기록·모델·백업 모두). 예전 버전이 켜져 있으면 트레이에서 '종료하기'로 끄고 다시 켜세요.
- 먼저 배포된 1.0에서 AI가 학생부 자료로 넣었던 전화번호·주소 같은 개인정보는 처음 켤 때 한 번 학생 명렬표로 옮깁니다. 직접 쓴 관찰은 건드리지 않습니다.

### 알아 두실 점
- AI가 만든 학생부 초안은 참고 자료입니다. 나이스에 옮기기 전에 사실과 기재요령을 꼭 확인해 주세요. 나이스에 자동으로 입력하지 않습니다.
- 그래픽카드가 없는 메모리 8GB PC에서는 기본형(2B) 이하 모델을 권합니다.
- 알림은 프로그램이 켜져 있을 때 뜹니다. '윈도우 시작 시 자동 실행'을 켜 두면 놓치지 않습니다.
