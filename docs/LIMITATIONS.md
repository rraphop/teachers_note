# 알려진 제한사항과 실행·데이터 위치 — 로컬 AI 교무수첩 1.0

## 1. 알려진 제한사항

### 배포·보안
1. **코드 서명이 없다.** 그래서 두 가지가 생길 수 있다.
   - 내려받은 파일을 처음 켤 때 "Windows의 PC 보호" 창이 뜬다([추가 정보] → [실행]).
   - 백신 오탐: 1.0 첫 빌드의 파일 하나 버전(묶음을 압축한 32MB)을 Windows 보안이 `Trojan:Win32/Sabsik.FL.A!ml` 로 잡아 격리했다. 지금은 묶음을 압축하지 않아(85MB) 이 PC 검사에서 깨끗하지만, 판정 모델이 바뀌면 다시 걸릴 수 있다. 막히면 ZIP 버전을 쓴다(검사 깨끗).
   - 근본 해결은 코드 서명 인증서다. 오탐은 Microsoft 보안 인텔리전스 파일 제출(https://www.microsoft.com/wdsi/filesubmission)로 신고할 수 있다.
2. 이미 웹 등에 올린 예전 1.0 파일(압축 묶음, 32MB)은 Windows 보안이 막는다. 새 빌드로 바꿔 올려야 한다.
3. 데이터는 암호화하지 않은 SQLite 파일이다. Windows 계정 보호에 기댄다. 내보낸 엑셀·PDF·백업에도 암호가 없다.

### AI
4. GPU 를 쓰지 않는다(CPU 전용). Qwen3.5 4B 로 기록 한 건 평균 약 6초(Ryzen 5 7600 기준). 메모리 8GB 학교 PC 에서는 2B 이하를 권한다.
5. AI 정리 결과는 참고용이다. 학생부 문장은 교사가 사실·기재요령을 확인해 고쳐 쓰고, 나이스에는 자동으로 넣지 않는다.
6. 분류 평가 세트가 작다(35건). 100% 는 그 세트에서의 결과다.

### 나이스
7. 인증키가 없으면 나이스가 5줄만 준다. 그래서 키 없이는 급식만 받고, 시간표·학사일정은 무료 인증키가 있어야 한다. 받은 자료는 하루 한 번 새로 받는다.
8. 나이스 시간표는 4주를 받아 요일·교시마다 가장 많이 나온 과목으로 만든다. 자주 바뀌는 수업은 맞지 않을 수 있다(칸을 직접 고치면 그대로 남음).
9. 학사일정의 휴일·휴업일·방학 구분은 나이스 구분값, 없으면 행사 이름 규칙으로 정한다. 학교마다 이름이 달라 설정에서 규칙을 고쳐야 할 수 있다.

### 프로그램
10. 알림은 프로그램이 켜져 있을 때만 뜬다. 꺼져 있던 동안의 알림은 다음 실행 때 ‘놓친 알림’으로 알린다(창을 닫아도 실행·윈도우 시작 시 자동 실행으로 보완).
11. 메모는 검색·엑셀 내보내기·학년도 기록물에 들어가지 않는다(백업에는 들어 있다).
12. 오늘 화면 직접 배치는 창이 좁으면 열을 접어 보여 주며, 그 상태에서는 칸을 옮길 수 없다.
13. 항상 위·투명도(최대 70%)·자동 실행은 Windows 에서만 된다. 자동 실행은 마지막으로 켠 교무수첩 파일을 가리킨다(파일을 옮기면 다시 한 번 켜야 고쳐진다).
14. Windows x64 전용이다. Microsoft Edge WebView2 런타임이 있어야 한다(Windows 10/11 대부분에 이미 있음).
15. 1.0 이전에 찍은 일부 캡처(`docs/screenshots` 20~25, 47~52, 58)와 지난 평가 결과(`docs/eval/*.json`)에는 예전 예시 이름(가짜 이름)이 남아 있다.
16. 기존 앱과 같은 입력으로 분류 품질을 나란히 잰 결과는 아직 없다(`COMPARISON.md` 4절).

### 학생 명렬표·학생부 자료 (2차 수정)
17. 기록 속 개인정보는 형식 규칙(전화번호, "주소 …", 시·도·시·군·구로 이어지는 주소, "생일 …", 학생개인번호 등)으로 찾는다. 형식이 다르게 적힌 정보(예: "집이 학교 앞 아파트")는 찾지 못할 수 있다.
18. 한 문장에 학생이 여럿이면 누구의 정보인지 정하지 않는다(명렬표에도, 학생부 자료에도 넣지 않고 알림만).
19. 출결 탭의 요약은 참고자료 글에서 규칙으로 읽은 횟수다. 나이스 출결 기록과 다를 수 있으니 최종안은 나이스와 맞춰 확인한다.
20. AI 정리 진행률은 받은 글자 수로 짐작한 값이라 실제 남은 시간과 꼭 맞지는 않는다.
21. 메뉴 옆 새 항목 숫자는 AI 가 넣은 항목만 센다(직접 만든 항목 제외). 이 기능이 들어간 빌드를 처음 켠 때부터 센다.

## 2. 실행 방법

| 형태 | 실행 | 처음 켤 때 |
|---|---|---|
| 파일 하나 | `교무수첩_1.0.0.exe` 를 바탕화면 등에 두고 실행 | `%LOCALAPPDATA%\TeacherNotebookV2\program\1.0.0` 에 프로그램을 풀고(약 3초) 실행. 다음부터는 파일 검사(SHA-256)만 하고 바로 실행 |
| ZIP | `TeacherNotebook-Portable-x64.zip` 을 풀고 `TeacherNotebook.exe` 실행 | 바로 실행 |

- 관리자 권한·설치가 필요 없다. 두 형태는 같은 데이터 폴더를 써서 오가도 기록이 이어진다.
- 업데이트: 새 파일(예: `교무수첩_1.0.1.exe`)을 같은 곳에 두고 켜면 지난 버전 파일(예전 이름 `교무수첩(0.9).exe` 등 포함)을 휴지통으로 옮길지 묻는다. 새 버전이 데이터 형식을 올리기 전에 ‘업데이트 전’ 백업을 만든다.

## 3. 데이터 위치 (`%LOCALAPPDATA%\TeacherNotebookV2`)

| 폴더·파일 | 내용 |
|---|---|
| `data\notebook.db` | 기록·학생·일정·할 일·업무·시간표·학생부 자료·메모·설정 (SQLite) |
| `backups\` | 백업 `notebook-날짜-시각-종류.db` (auto: 하루 한 번, manual: 지금 백업, before-restore: 되돌리기 직전, before-update: 데이터 형식 올리기 전) |
| `models\` | 설치한 AI 모델(.gguf) |
| `program\<버전>\` | 파일 하나 버전이 풀어 쓰는 프로그램 (지난 버전 폴더는 자동 정리) |
| `rules\` | 규칙 파일 |
| `logs\` | 실행 기록 |
| `webview\` | 화면(WebView2) 캐시 |

- 프로그램 폴더를 옮기거나 새 버전으로 바꿔도 데이터는 그대로 남는다.
- 설정 → 데이터에서 위치 열기·지금 백업·되돌리기·모든 로컬 데이터 삭제를 할 수 있다.
- 인터넷은 AI 모델을 받을 때와 나이스(학교 코드만 보냄)에만 쓴다.
