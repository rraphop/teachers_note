# 기존 앱과 비교 — 로컬 AI 교무수첩 1.0 (V2)

- **기존 앱**: 같은 이름의 앞선 구현. 2026-09-29 최종본(`dist-portable-final-20260929`), 그 앱의 `README.md`·`docs/verification-report.md` 기준.
- **V2 1.0**: 이 저장소. 처음부터 다시 만든 독립 구현(코드를 가져오지 않음).
- 기존 앱 내용은 문서에 적힌 기능 기준이다. 같은 입력으로 분류 품질을 나란히 재는 시험은 아직 하지 않았다(아래 4절).

## 3. 같은 점 (설계 원칙)

- 학생 정보는 PC 밖으로 보내지 않는다(AI 는 이 PC 안 llama.cpp).
- 관리자 권한 없이 Portable 로 실행한다.
- 모델 파일은 크기·SHA-256 확인 뒤에만 설치한다.
- 나이스에 자동으로 입력하지 않는다(교사가 검토해 옮긴다).

## 4. 아직 하지 않은 비교

- **같은 입력으로 분류 품질 나란히 재기**: 기존 앱은 목록에 있는 모델만 내려받아 쓸 수 있고(파일로 설치 없음), 그 목록에 이 PC에 있는 Qwen3.5 4B 가 없다. 나란히 재려면 기존 앱 목록 모델(가장 작은 것: Qwen2.5 0.5B, 491MB)을 Hugging Face 에서 내려받아야 한다. 준비된 도구: `scripts/e2e/run-eval-old.mjs`(같은 세트·같은 채점), `scripts/e2e/old-app-data.ps1`(기존 앱 데이터 백업·복원).
- V2 쪽 Qwen2.5 0.5B 결과(보정 전)는 개발 52/52, 홀드아웃 36/38 이다(`docs/eval/*-qwen2.5-0.5b.json`).
