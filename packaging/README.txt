로컬 AI 교무수첩 (Local Teacher Notebook) 1.0.1 — Windows 10/11 x64

생각나는 대로 한 줄 적으면, 이 PC 안의 AI가 할 일·일정·학생 기록·교무 업무로 나눠 정리해 줍니다.
학생 개인정보는 이 PC 밖으로 나가지 않습니다. 설치도, 관리자 권한도 필요 없습니다.


■ 처음 5분: 이것만 하면 됩니다

  1. 실행하기
     - 파일 하나 버전: Teachers_Note_1.0.1.exe (또는 이름을 바꾼 교무수첩_1.0.1.exe)를 바탕화면 등에 두고 실행합니다.
       처음 켤 때와 새 버전으로 바꾼 뒤 한 번은 '준비 중' 창이 뜨고 3초쯤 걸립니다.
     - 압축(ZIP) 버전: Teachers_Note_1.0.1_portable.zip 을 풀고 teachers_note 폴더의 teachers_note.exe 를 실행합니다.
       백신이 파일 하나 버전을 '스스로 파일을 푸는 프로그램'이라며 막을 때 쓰세요.
     - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다. (코드 서명이 없는 프로그램이라 뜹니다)

  2. AI 모델 받기 (처음 한 번)
     설정 > AI 모델에서 'PC 권장' 표시가 붙은 모델의 [받기]를 누릅니다.
     모델이 없어도 기록은 저장되고, 나중에 기록 화면의 [모두 AI로 분류]로 한꺼번에 정리할 수 있습니다.

  3. 학교 정하기
     설정 > 학교(나이스)에서 학교 이름으로 찾아 고르고 담임반을 정합니다. 급식은 바로 받아옵니다.
     나이스 인증키를 넣으면 시간표·학사일정도 받습니다(무료: open.neis.go.kr 회원가입 → '인증키 신청').
     같은 화면의 '내 과목'을 고르면 학교 시간표에서 내 수업만 모아 개인 시간표를 만듭니다.

  4. 학생 명렬표 넣기
     나이스 → 학적 → 기본학적관리 → 명렬표출력 → 학급별 조회 → 엑셀파일 다운로드로 받은 파일을
     학생 명렬표 화면의 [나이스 명렬표 가져오기]로 고르거나 화면에 끌어다 놓습니다. 여러 학급을 한꺼번에 넣어도 됩니다.

  5. 적기
     화면 맨 아래 입력창에 적고 [기록] 또는 Ctrl+Enter. 분류를 고를 필요가 없습니다.
       예) 금요일까지 상담 신청서 걷기            → 할 일 (마감 금요일)
           오늘 1교시 2-1 ○○○ 지각                → 학생부 자료 · 출결
           3-1 ○○○ 번호는 21번                    → 학생 명렬표 · 번호
           ○○○ 어머니 연락처 010-0000-0000        → 학생 명렬표 · 보호자 연락처
           다음 주 수요일 15시 학년 협의회         → 일정
           월 3교시 2-1 국어 과학실                → 개인 시간표
           OO군청에 행사 일정 물어봄               → 기타 기록 (이미 한 일은 할 일로 만들지 않음)


■ 화면 안내

  [오늘]  오늘 업무 요약, 할 일, 오늘 시간표, 급식, 메모, 오늘의 기록.
          칸은 화면 너비에 맞춰 1~4열로 놓이고, [칸 배치]로 끌어 옮기거나 숨길 수 있습니다([자동 배치]로 처음처럼).
          메모는 날이 바뀌어도 남는 스티커 메모입니다(색 6가지, 지운 메모는 바로 [되돌리기]).

  [일정표]  주간·월간·학사력. 학사력은 휴일·휴업일 빨강, 방학 초록, 그 밖의 학사 일정은 청회색입니다.

  [시간표]  개인·학급·전체 시간표. 칸을 고치고 다른 칸으로 옮기면 바로 저장됩니다.
          탭 줄 오른쪽 끝 톱니에서 일과 시간과 방과후(요일별)를 정하고, [색칠하기]로 교과·교사·학급·교실별 색을 정합니다.
          입력창에 "화·목 1교시 3-2 수학"처럼 적으면 개인 시간표에, "10월 5일 2교시 3-1과 교체"처럼 날짜를 적으면
          그날만 바뀌는 '시간표 변경'으로 들어갑니다. 이미 수업이 있는 칸은 덮어쓰지 않고 [바꾸기]/[그대로]를 묻습니다.

  [기록]  적은 기록 원문. 세 탭으로 봅니다.
          - 모든 기록: 전부, 최근 것부터
          - 기타 기록: AI가 할 일·일정·업무·학생 관찰을 찾지 못한 기록
          - 정리된 기록: AI가 정리한 기록
          [정리된 기록으로 보내기] / [기타 기록으로 되돌리기]로 직접 옮긴 기록은 AI가 다시 분류해도 그대로입니다.
          AI가 틀렸으면 기록 카드의 [분류 수정]이나 [AI로 다시 분류]를 누릅니다.
          AI가 정리하는 동안 [기록] 버튼 왼쪽 원형 게이지가 차오르고, 새 항목이 생긴 메뉴 옆에 초록 숫자가 뜹니다.

          기록 안에서 찾기 (기록 화면 위 찾기 칸, 지금 탭과 날짜 안에서 찾고 찾은 말을 노랗게 표시)
          - 낱말 모두(기본): "상담 보호자" → '상담'과 '보호자'가 둘 다 든 기록 (붙어 있지 않아도 됨)
          - 구 그대로: [구 그대로]를 고르고 "보호자 연락" → 띄어쓰기까지 그대로 든 기록
          - 섞어 쓰기: "진로 상담" 보호자 → 따옴표로 묶은 구와 낱말이 모두 든 기록
          - Esc 나 [지우기]로 다시 전부. 학생·할 일·일정까지 한꺼번에 찾으려면 왼쪽 메뉴 [검색].

  [학생 명렬표]  카드와 학급명렬표 두 보기. 칸을 눌러 바로 고칩니다.
          - 찾기: "1-1", "1학년", "3번"으로도 찾고, 결과가 하나면 Enter 로 학생 상세. 찾는 중엔 [엑셀로 저장]·[인쇄]도 찾은 학생만.
          - 보일 항목: 전화번호·보호자 연락처·주소·생일 등을 골라 봅니다. 학급·번호·이름 칸은 가로로 밀어도 왼쪽에 붙어 있습니다.
          - 학생 추가: 표 아래 줄에서 학급을 고르면 다음 번호가 들어가고, 이름 + Enter. 없는 학급은 '+ 새 학급'.
          - 연락처·주소 가리기: 수업 화면에 띄울 때 켭니다(기록 화면에도 함께 적용).
          - 기록에 적은 번호(출석번호)·전화번호·보호자 연락처·주소·성별·생일·학생개인번호·이전학적은 학생부 자료가 아니라
            명렬표의 그 학생 칸으로 들어갑니다.
            · 칸이 비어 있으면 바로 넣고, 이미 값이 있으면 기록 카드에서 "기존 → 새 값"을 보여 주며 [바꾸기]/[그대로 두기]를 묻습니다.
            · 번호는 "○○○ 번호는 21번"처럼 이름 바로 뒤에 '번호'를 적을 때만 넣습니다("문항 번호 3번" 같은 다른 번호는 넣지 않음).
              같은 학급에 이미 그 번호 학생이 있으면 먼저 묻습니다.
            · 보호자 연락처는 관계와 번호로 4개까지. 4개가 찬 뒤 새 번호가 오면 어느 번호를 바꿀지 고릅니다.
            · "수업 중 자주 어지러움 호소"처럼 특이사항으로 보이는 내용은 [학생부 자료]와 [학생 명렬표 특이사항] 중 어디에 둘지 묻습니다.
            · 한 문장에 학생이 여럿이면 누구의 정보인지 정할 수 없어 넣지 않고 기록 카드에 알려 드립니다(학생별로 나눠 적어 주세요).
            · 전학 기록("2-1 ○○○ OO중 전학 예정", "OO중에서 전입생 옴, 이름 ○○○")은 학생부 자료가 아니라 명렬표 비고에 이어 적고
              '○○○ 전출(전입) 서류 처리' 할 일을 만듭니다. 명렬표에 없는 전입생은 '확인 필요' 학생으로 추가합니다.
            · 학생 상세 아래 '명렬표 변경 이력'에서 무엇이 언제 어느 기록에서 들어왔는지 봅니다.
          - 주소·우편번호는 학생 상세에서 [눌러서 보기]를 눌러야 보입니다. 주민등록번호는 기본으로 저장하지 않습니다.

  [학생부 자료]  학생 이름을 넣어 적은 기록이 영역 8개로 모입니다.
          출결(결석·지각·조퇴·결과를 질병·미인정·기타·출석 인정으로 집계), 창체 자율·자치, 교과(과목별), 행특, 동아리, 진로,
          자유학기(활동별), 일상생활.
          [참고자료 모아 붙이기] 또는 [AI 초안 만들기](참고자료만 근거, 근거에 없는 표현은 노란색) → 고쳐 쓰고
          [초안으로 저장]/[최종안으로 저장] → [복사]. 학생 목록의 ● 최종안 ◐ 초안 ○ 참고자료만.
          글자 수와 나이스 바이트(한글 3, 엔터 1)를 바로 보여 주고 2026학년도 중학교 기재요령 한도를 넘으면 알립니다
          (출결 특기사항·자율·자치·동아리·진로·교과 500자, 행특 300자, 자유학기 활동별·일상생활 1,000자).
          ※ AI 초안은 교사가 검토하는 자료입니다. 그대로 나이스에 옮기지 말고 사실과 기재요령을 확인해 고쳐 써 주세요.
             나이스에 자동으로 입력하지 않습니다.

  [교무 업무]  시험감독·보강·출장·연수·당직처럼 나에게 배정된 일은 담당업무를 등록하지 않아도 교무 업무로 남습니다('업무 미지정').
          업무분장표의 내 업무를 [담당업무 등록](업무명 + 세부업무)하면 기록이 업무별로 모입니다.
          세부업무에 쉼표로 적은 짧은 낱말(예: 학사력, 수업일수)은 AI가 없어도 분류에 쓰입니다.

  [할 일]  기록에서 "~까지", "제출", "연락할 것"처럼 앞으로 할 일만 뽑습니다. "물어봄", "통화함"처럼 이미 한 일은 할 일이 아닙니다.
          체크하면 "10월 9일 14:20 완료 · 제목" 완료 기록이 담당업무의 업무 기록(없으면 기타 기록)으로 남고, 체크를 풀면 지워집니다.

  [검색]  기록·학생·할 일·일정 전체 검색.


■ 알림과 창

  - 할 일·업무·일정마다 7일 전·3일 전·2일 전·1일 전·당일·직접 정한 시각 알림을 고릅니다.
    알림은 교무수첩이 켜져 있을 때 화면 오른쪽 아래에 뜨고, 꺼져 있던 동안의 알림은 다음에 켤 때 '놓친 알림'으로 알려 드립니다.
    설정 > 알림 > [테스트 알림 보내기]로 확인할 수 있습니다.
  - 창의 X 를 누르면 꺼지지 않고 시계 옆 알림 영역(트레이)에 남아 AI 정리와 알림을 계속합니다.
      아이콘 두 번 누르기 / '열기'  창 열기
      '기록하기'                    작은 입력창만 띄우기 (Enter 저장, Shift+Enter 줄바꿈, Esc 닫기)
      '닫기'                        창만 숨기기
      '종료하기'                    완전히 끄기 (AI가 정리 중인 기록이 있으면 먼저 묻고, 원문은 다음에 이어서 정리)
  - 왼쪽 메뉴 '설정' 아래: '윈도우 시작 시 자동 실행'(알림을 놓치지 않음), '항상 위에 표시', '투명도'(0~70%).


■ AI와 그래픽카드

  - AI 엔진(llama.cpp)이 들어 있어 Ollama·Python 같은 다른 프로그램을 설치할 필요가 없습니다.
  - 외장 그래픽카드가 있고 그래픽 메모리가 넉넉하면 GPU로, 아니면 CPU로 돕니다. 그래픽 드라이버만 있으면 됩니다.
    GPU로 켜다 문제가 생기면 저절로 CPU로 다시 켭니다. 화면 왼쪽 아래에 "AI 준비됨 · GPU / CPU"로 보입니다.
    설정 > AI 모델 > 'AI 계산 장치'에서 '자동 / CPU 만'을 고를 수 있습니다(다음에 AI 엔진을 켤 때부터 적용).
  - 모델 고르기 (권장 PC 메모리): 초경량형 0.5B(4GB, 확인용) · 기본형 2B(8GB, 학교 PC 권장) · 고급형 4B(16GB)
    · 최고급형 Gemma 4 E4B(24GB) · 울트라 9B(32GB). 받은 파일은 크기와 SHA-256 을 확인한 뒤에만 설치되고, 끊기면 이어받습니다.
    다른 PC에서 받은 모델 파일(.gguf)은 [파일로 설치]로 USB 등에서 바로 넣을 수 있습니다.


■ 저장·백업·내보내기

  - 데이터 위치: 기록·학생·일정·AI 모델은 프로그램 파일이 아니라 아래에 저장됩니다.
      %LOCALAPPDATA%\teachers_note\
        data\notebook.db   기록 데이터베이스
        models\            AI 모델 파일
        backups\           자동 백업 (하루 한 번, 최근 14개)
        logs\              기술 로그 (학생 이름·원문은 남기지 않음)
    그래서 프로그램 파일을 옮기거나 새 버전으로 바꿔도 기록과 모델이 그대로 남습니다.
  - 따로 저장하지 않아도 되는 것: 기록(쓰다 만 글 포함), 학급명렬표·시간표 칸, 오늘 화면 메모
    [저장]을 눌러야 하는 것: 일정·할 일·업무 편집 창, 일과 시간 설정, 학생부 초안·최종안
  - 백업과 되돌리기: 설정 > 데이터 > [지금 백업], 백업 목록의 [되돌리기]. 되돌리기 직전 데이터는 '되돌리기 전' 백업으로 먼저 남습니다.
  - 엑셀·CSV로 내보내기: 설정 > 엑셀·CSV로 내보내기. 학급명렬표·기록 원문·학생 관찰·학생부 초안·할 일·일정·업무·시간표.
    내보낸 파일에는 암호가 없으니 보관·전달에 주의해 주세요.
  - 학년도 마감과 새 학년도: 설정 > 학년도 마감과 새 학년도
      [학년도 마감 기록물 만들기]  학사·업무 기록.pdf, 학생 기록.pdf(PDF/A, 책갈피), 엑셀 원본.xlsx, 교무수첩 백업.db,
                                   읽어보기.txt, SHA256SUMS.txt 를 '2026학년도 교무수첩 기록물' 폴더에
      [새 학년도 시작]             먼저 자동 백업 → 지난 학년도 학생 보관(목록에서 숨김, 기록은 그대로) → 일과 시간·시간표를 새 학년도로
                                   잘못 눌렀다면 설정 > 데이터의 '새 학년도 전' 백업으로 되돌립니다.


■ 새 버전으로 바꿀 때

  - 파일 하나 버전: 새 버전 파일(예: Teachers_Note_1.0.2.exe)을 같은 곳에 두고 켭니다. 지난 버전 파일을 휴지통으로 옮길지 묻습니다
    (예전 이름의 교무수첩(0.9).exe, 교무수첩(1.0).exe 등도). 지난 버전 파일을 잘못 켜면 새 버전을 쓰라고 알려 줍니다.
    프로그램 파일은 %LOCALAPPDATA%\teachers_note\program\<버전> 에 풀어 쓰고 켤 때마다 SHA-256 으로 검사해, 망가졌으면 다시 풉니다.
  - ZIP 버전: 새 ZIP 을 풀어 프로그램 폴더를 바꿉니다(덮어써도 됨).
  - 어느 쪽이든 기록·학생·일정·AI 모델은 그대로이고, 새 버전이 처음 켜질 때 데이터 형식만 자동으로 올립니다.
    바꾸기 전에 [지금 백업]을 한 번 눌러 두면 더 안전합니다.
  - 1.0 첫 배포까지는 데이터 폴더가 %LOCALAPPDATA%\TeacherNotebookV2 였습니다. 이 버전을 켜면 그 폴더 이름을 teachers_note 로
    바꿔 그대로 옮깁니다(기록·AI 모델·백업 모두). 예전 버전이 켜져 있으면 닫고 다시 켜면 옮겨집니다.

■ 문제가 생기면

  - "Windows의 PC 보호" 창        [추가 정보] → [실행]
  - 백신이 파일 하나 버전을 막음   압축(ZIP) 버전 사용
  - 화면이 뜨지 않음               Microsoft Edge WebView2 런타임 확인 (Windows 10/11 대부분에 이미 있음)
  - 시간표·학사일정이 안 들어옴    설정 > 학교(나이스)에 인증키 넣기 (키가 없으면 나이스가 5줄만 줘서 받지 않음)
  - AI 정리가 느림                 더 작은 모델, 또는 외장 그래픽카드가 있으면 'AI 계산 장치'를 '자동'으로
  - 개인정보가 명렬표에 안 들어감   한 문장에 학생 한 명만, 기록 카드에 확인 단추가 남아 있는지 보기
  - 받은 파일 확인                 PowerShell 에서 Get-FileHash .\Teachers_Note_1.0.1.exe → 릴리스 페이지의 SHA-256 과 비교
                                   (ZIP 버전은 폴더 안 SHA256SUMS.txt 에 모든 파일의 값이 있음)
  - 지우기                         데이터까지 지우려면 먼저 설정 > 데이터 > 모든 로컬 데이터 삭제, 그다음 프로그램 파일을 지웁니다.
