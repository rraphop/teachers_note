로컬 AI 교무수첩 (Local Teacher Notebook) — Windows x64 Portable

■ 실행 방법
  1. ZIP 파일을 원하는 폴더에 압축 해제합니다. (관리자 권한 필요 없음)
  2. TeacherNotebook.exe 를 실행합니다.
  3. 첫 화면 맨 위 입력창에 생각나는 대로 적고 [기록] 또는 Ctrl+Enter 를 누릅니다.
     카테고리를 고를 필요가 없습니다. AI가 학생·할 일·일정·업무로 정리합니다.

  * 인터넷에서 받은 ZIP 이면 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다.
    [추가 정보] → [실행]을 누르면 됩니다. (서명되지 않은 프로그램이기 때문입니다)
  * 화면이 뜨지 않으면 Microsoft Edge WebView2 런타임이 필요한지 확인하세요.
    Windows 10/11 대부분에는 이미 들어 있습니다.

■ AI 모델 설치 (처음 한 번)
  설정 > AI 모델에서 'PC 권장' 표시가 있는 모델의 [받기]를 누릅니다.
  - 초경량형(0.5B), 기본형(2B, RAM 8GB 학교 PC 권장), 고급형(4B), 최고급형, 울트라 중에서 고릅니다.
  - 받은 파일은 크기와 SHA-256 을 확인한 뒤에만 설치됩니다. 끊기면 이어받을 수 있습니다.
  - 다른 PC에서 받은 모델 파일(.gguf)은 [파일로 설치]로 USB 등에서 바로 설치할 수 있습니다.
  - AI 모델이 없어도 기록은 저장되고, '직접 분류'로 정리할 수 있습니다.
    모델을 설치한 뒤 기록 화면의 [모두 AI로 분류]로 한 번에 정리할 수 있습니다.
  - Ollama, LM Studio, Python 등 다른 프로그램을 설치할 필요가 없습니다.
    AI 엔진(llama.cpp)이 runtime 폴더에 들어 있습니다.

■ 개인정보
  기록과 AI 처리는 이 PC 안에서만 이루어집니다. 학생정보를 외부 AI 서비스로 보내지 않습니다.
  사용 기록을 수집하지 않습니다. 인터넷은 AI 모델 파일을 받을 때만 씁니다.
  AI 엔진은 이 PC 내부 전용 주소(127.0.0.1)에서만 연결을 받고, 실행할 때마다 새 인증키를 씁니다.

■ 데이터 위치
  기록·학생·일정·모델은 프로그램 폴더가 아니라 아래 위치에 저장됩니다.
    %LOCALAPPDATA%\TeacherNotebookV2\
      data\notebook.db   기록 데이터베이스
      models\            AI 모델 파일
      backups\           자동 백업 (하루 한 번, 최근 14개)
      logs\              기술 로그 (학생 이름·원문은 기록하지 않음)
  그래서 프로그램 폴더를 옮기거나 새 버전 ZIP 으로 바꿔도 기록과 모델이 그대로 남습니다.
  설정 > 데이터에서 위치를 열거나, 지금 백업하거나, 모든 로컬 데이터를 지울 수 있습니다.

■ 알림
  할 일·업무·일정마다 7일 전, 3일 전, 2일 전, 1일 전, 당일, 직접 정한 시각 알림을 고를 수 있습니다.
  알림은 교무수첩이 실행 중일 때 화면 오른쪽 아래에 표시됩니다.
  프로그램이 꺼져 있던 동안의 알림은 다음 실행 때 '놓친 알림'으로 알려 드립니다.
  설정 > 알림에서 '창을 닫아도 계속 실행'이나 'Windows 로그인 때 자동 시작'을 켜면 놓치지 않습니다.
  설정 > 알림 > [테스트 알림 보내기]로 이 PC에서 알림이 보이는지 확인할 수 있습니다.

■ 학생부 자료
  학생별 관찰 기록이 7개 영역(출결, 교과, 자율, 진로, 봉사, 동아리, 행동특성 및 종합의견)으로 모입니다.
  초안은 교사가 검토하는 자료이며, 학생부(NEIS)에 자동으로 입력하지 않습니다.
  AI 초안에서 근거 기록에 없는 표현은 노란색으로 표시됩니다.

■ 무결성 확인
  SHA256SUMS.txt 에 모든 파일의 SHA-256 이 들어 있습니다.

■ 지우기
  프로그램 폴더를 지우면 프로그램이 지워집니다.
  데이터까지 지우려면 먼저 설정 > 데이터 > 모든 로컬 데이터 삭제를 쓰세요.
